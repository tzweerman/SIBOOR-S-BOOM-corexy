# SIBOOR-S-BOOM-2026

This is my fork of the siboor Boom 3d printer, i am trying to redesign and rebuild this 3d printer into a corexy printer.

it uses VORON TAP, the phaetus taichi hotend and the rainbowdragon toolhead (https://github.com/chirpy2605/voron#rainbow-dragon)
